### Real-server LSP interop fixes (2026-09-29)

真机测试用真实 pyright 1.1.414 / typescript-language-server 6.0.1 跑通全链路，暴露并修复：

1. **`rename` 只认 legacy `changes`** —— 真服务器返回 LSP 3.16+ `documentChanges`（pyright/tsserver 均如此），原实现永远返回 `[]`。现两种 shape 都解析。
2. **pyright `workspace/symbol` 在 stdio 会话恒返回 `[]`**（能力位有声明但索引不生效，属 pyright 已知行为）—— `symbols()` 增加 documentSymbol 树兜底（对打开的文件扁平化 + 子串过滤 + containerName）。
3. **服务器→客户端请求无人应答**（如 `window/workDoneProgress/create`）—— 按 JSON-RPC 规范回 `result: null`，避免服务器停滞。

环境坑：typescript-language-server 6.x 从**被分析 workspace**解析 `typescript`（无则 initialize 直接失败），测试 fixture 需把 monorepo 的 typescript 软链进临时 workspace；其 CLI 也不再有 `--tsserver-path`（改走 initializationOptions）。
